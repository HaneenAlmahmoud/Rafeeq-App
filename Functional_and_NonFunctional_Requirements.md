# Rafeeq
مشروع رفيق: مساعد ذكي صوتي لكبار السن
## Functional Requirements

1. The system shall allow users to interact with the application using Saudi Arabic voice commands.
2. The system shall convert speech to text using speech recognition.
3. The system shall identify the user's intent using AI.
4. The system shall respond to users in spoken Arabic.
5. The system shall allow users to create medication reminders.
6. The system shall allow users to create appointment reminders.
7. The system shall display prayer times and send notifications.
8. The system shall allow users to play the Holy Quran.
9. The system shall provide nutrition advice for elderly users.
10. The system shall locate the nearest mosque, hospital, or pharmacy.
11. The system shall save user data and reminders.
12. The system shall provide an emergency call button.

## Non-Functional Requirements

1. Response time shall not exceed 3 seconds for most operations.
2. The system shall be available 24/7.
3. User data shall be protected and kept confidential.
4. The system shall support Arabic and the Saudi dialect.
5. The interface shall be simple, with large buttons and readable text.
6. The application shall support Android and iOS.
7. Scheduled reminders shall continue to work offline.
8. The system shall be reliable and stable.
9. Speech recognition accuracy shall be high.
10. The system shall comply with privacy requirements.
