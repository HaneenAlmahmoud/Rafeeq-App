# Rafeeq – UI Showcase

This document presents the main user interfaces designed and implemented for the Rafeeq application using FlutterFlow. The interfaces were designed with a focus on simplicity, accessibility, and ease of use for older adults.

## 1. Login Interface

A simple login and verification interface designed to provide a clear and straightforward entry experience.

## 2. Main Voice Assistant Interface

The main interface centers around Rafeeq's voice assistant, providing users with an accessible way to interact with the application through voice commands.

## 3. Services Dashboard

A centralized dashboard providing easy access to Rafeeq's main services, including the Quran, daily schedule, prayer times, personal information, family contacts, settings, and memory games.

## 4. Quran Interface

Provides access to Quran Surahs with audio playback functionality through a simple and accessible interface.

## 5. Daily Schedule

Allows users to view and manage daily tasks, appointments, and medication reminders.

## 6. Prayer Times

Displays daily prayer times and provides access to prayer-related reminder settings.

## 7. Family Contacts

Allows users to access family members and provides convenient contact and location options.

## 8. Personal Information

Organizes the user's basic personal and health information in a clear and accessible format.

## 9. Reminder Interface

Displays important upcoming reminders prominently on the main voice-assistant interface.

## 10. Memory Games

Provides simple cognitive activities designed to support memory stimulation.

### Card Matching

A card-matching activity where users identify and match identical pairs.

### Color Memory

A sequence-based activity where users observe and repeat a displayed sequence of colors.

---

## Design Principles

The interfaces were developed around several key principles:

- Simple and consistent navigation
- Clear Arabic typography
- Arabic right-to-left (RTL) design
- Large and recognizable interface elements
- Reduced visual complexity
- Voice-first interaction
- Accessibility for older adults
